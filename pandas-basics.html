01

Pandas 是什么

pandas 是 Python 的数据分析核心库：读表格、清洗数据、统计分析、做特征，都靠它。它只有两个核心数据结构：

Series —— 一维

带索引的一列数据，相当于"有编号的列表"。

DataFrame —— 二维

多列组成的表格，类似 Excel 表，日常分析主要用它。

import pandas as pd

# Series：一维
s = pd.Series([10, 20, 30])

# DataFrame：二维表格（最常用）
df = pd.DataFrame({
    "姓名": ["小明", "小红", "小刚"],
    "年龄": [18, 17, 19],
    "分数": [92, 85, 78]
})

df.head()      # 看前几行
df.info()      # 列名、类型、缺失情况
df.describe()  # 数值列统计摘要

df 长这样

   姓名  年龄  分数
0  小明   18   92
1  小红   17   85
2  小刚   19   78
02

缺失值填充：ffill / bfill

现实数据经常有空值（NaN），而统计和模型都容不下 NaN，所以要先填充。 两个方向，一句话分清：

  • ffill（forward fill）：拿前一个有效值往下补空位
  • bfill（backward fill）：拿后一个有效值往回补空位
import pandas as pd

temps = pd.DataFrame({
    "气温": [28.0, None, None, 25.0]
})

temps.ffill()   # 拿"前一个"有效值填空

输出

    气温
0  28.0
1  28.0
2  28.0
3  25.0
temps.bfill()   # 拿"后一个"有效值填空

输出

    气温
0  28.0
1  25.0
2  25.0
3  25.0
记忆口诀：ffill 抄前桌的答案，bfill 抄后桌的答案。 注意：两者都返回新对象，不改动原表；要就地修改用 temps.ffill(inplace=True)。
03

类别编码：get_dummies

模型只认数字，不认"北京 / 上海"这种文字。get_dummies 把一个分类列拆成多个 0/1 列（独热编码），一行代码搞定： 

import pandas as pd

df = pd.DataFrame({
    "姓名": ["小明", "小红", "小刚"],
    "城市": ["北京", "上海", "北京"],
    "分数": [92, 85, 78]
})

pd.get_dummies(df, columns=["城市"], dtype=int)

输出

   姓名  分数  城市_北京  城市_上海
0  小明   92       1       0
1  小红   85       0       1
2  小刚   78       1       0
两个细节： columns= 指定要编码的列，不写则对所有文本列生效； dtype=int 让结果是 0/1，否则新版 pandas 默认返回 True/False。
