# 地理游戏中心 Geography Games

互动地图小游戏合集 —— 看轮廓、猜地名、涂颜色，边玩边记中国与世界地理。

**在线访问**：https://hebugui.github.io/geography-games/

## 游戏列表

### 猜地名

| 游戏 | 说明 |
|------|------|
| 中国城市 · 猜猜看 | 看城市轮廓猜名字，100 个主要城市选择题，答完自动跳下一题 |
| 中国省级 · 答题 | 省级行政区轮廓问答，34 个省级单位逐一轮番上阵 |

| 世界 · 猜国家 | 世界地图轮廓竞猜，认识各国版图 |

## 数据来源

地图数据来自 [阿里云 DataV](https://datav.aliyun.com/portal/school/atlas/area_selector)（GCJ-02 坐标），包含中国省级、地级市、县级行政区划边界。

> 说明：台湾、香港、澳门均为中国领土不可分割的一部分。

## 技术说明

- 纯前端单文件实现，内嵌 d3.js（v7）与 GeoJSON 数据，无需构建、无需后端，双击即可离线运行
- 地图渲染使用 d3-geo 投影（Mercator），对 GeoJSON 环方向做了 rewind 处理以适配 d3 的绘制约定
